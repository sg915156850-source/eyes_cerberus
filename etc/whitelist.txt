# Process names (ps `comm`, exact match, max 15 chars as the kernel truncates)
# that Cerberus must never flag for sustained high CPU (`high_cpu`). One name
# per line; spaces inside a name are kept, so "npm exec vite p" works.
#
# Every other detector ignores this list on purpose -- `miner` included: a
# miner can rename itself to anything on it, so a whitelisted name would be the
# cheapest way to make a CPU-hot miner look harmless. The same goes for the
# C2, known-hash and known-path detectors.
#
# Keep this conservative: only add names you are certain are benign on this host.

# --- interpreters / app servers ---
python3
node
uvicorn
gunicorn

# --- databases ---
postgres
redis-server

# --- web / proxy ---
nginx

# --- system daemons that legitimately spike CPU ---
systemd
unattended-upgr
fwupd
packagekitd
apt
apt-get
dpkg
snapd
mandb
man-db.periodic

# --- backup / archive / sync (routine heavy CPU) ---
pg_dump
pg_basebackup
pg_restore
rsync
tar
gzip
pigz

borg
restic

# --- ops tooling ---
sshd
